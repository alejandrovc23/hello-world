# Overview

This TypeScript program prints `Hello World` in the terminal. My goal is to check that I can run a TypeScript file and see its output before building a larger command-line project.

# Development Environment

The program runs with Node.js and was tested with version 24.18.0 in PowerShell on Windows. The TypeScript source declares a string and passes it to `console.log`.

From the project folder, run:

```sh
node hello.ts
```

Expected output:

```text
Hello World
```
